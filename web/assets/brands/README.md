# Logos de fabricantes en Cyberverse

Coloque aquí los archivos SVG oficiales autorizados, sin cambiar sus marcas, usando estos nombres:

- `sophos.svg`
- `crowdstrike.svg`
- `fortinet.svg`
- `acronis.svg`
- `kaseya.svg`
- `cato.svg`
- `nexusguard.svg`
- `datto.svg`
- `secureworks.svg`

La interfaz carga estos recursos localmente, también al abrir `index.html` sin hosting. Si falta uno, se presenta automáticamente un rótulo tipográfico del fabricante y nunca queda un espacio en blanco.

No se incluyen imitaciones ni recreaciones de logotipos oficiales. Solicite los archivos al equipo de alianzas o desde las guías de marca de cada fabricante. Evite SVG de terceros sin verificar su origen y procedencia.
